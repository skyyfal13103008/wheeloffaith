# Wheel of Faith

A character generator in the style of the TikTok "wheel of fate" spinners. Spin one wheel per trait (race, power, weapon, personality, fate...) and the character sheet fills in as you go.

- Three themes: Shonen anime, Fantasy RPG, Superhero
- Spin one trait at a time or "Spin all"
- Limited rerolls per character (0 to unlimited)
- Edit any wheel, add your own wheels, saved in your browser
- Copy the finished character as text, past characters kept below

## Run it

Open `index.html` in a browser. No install needed.

## Editing

The page source lives in `src/wheel.html`. After editing it, run `./build.sh` to regenerate `index.html`.
